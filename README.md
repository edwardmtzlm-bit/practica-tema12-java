# Practica Tema 12

Práctica desarrollada para la materia Computación en Java utilizando IntelliJ IDEA.

## Descripción
El programa implementa un sistema básico de agenda de contactos utilizando manejo de archivos en Java.

## Funciones principales
- Agregar contactos
- Guardar información en archivo de texto
- Leer contactos almacenados
- Menú interactivo en consola

## Tecnologías utilizadas
- Java JDK 11
- IntelliJ IDEA
- Git y GitHub
